# Canteen launcher icons

Circular home icons for `/canteen`. Name files by canteen id:

```text
public/assets/canteen-icons/<canteen-id>.png
```

Also accepted: `.webp`, `.jpg`, `.jpeg`, `.svg`.

Prefer square images (they are cropped to a circle). Name by canteen **name** or UUID, e.g. `ws-can.png`. When missing, the UI shows a temporary mock icon.
