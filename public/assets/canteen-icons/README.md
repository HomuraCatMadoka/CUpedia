# Canteen launcher icons

Squircle launcher icons for `/canteen`. Name files by canteen id:

```text
public/assets/canteen-icons/<canteen-id>.png
```

Also accepted: `.webp`, `.jpg`, `.jpeg`, `.svg`.

Prefer square images; the UI fits them inside a rounded-square tile. Name by
canteen **name** or UUID, e.g. `ws-can.png`. When missing, the UI shows a
stable short-name wordmark.
