# 公告（Announcements）

面向全站读者发布重要更新，并可在首次公开时向现有 User 投递站内通知。公告正文公开可读；编写与状态管理仅限 Admin。

本文件只是术语表，不记录实现。

## Language

**草稿（Draft）**:
尚未安排公开时间的公告。只在后台可见，可继续编辑或永久删除。
_Avoid_: 未发布（会混淆待发布公告）。

**待发布（Scheduled announcement）**:
已指定未来公开时间的公告。在该时间前只在后台可见；Admin 可修改排期、清空排期改为立即发布，或关闭发布将其恢复为「草稿」。
_Avoid_: 草稿；把排期本身当成已经公开。

**已发布（Published announcement）**:
已经到达当前公开时间、尚未失效或撤回的公告。显示在首页近期公告、全部公告与详情页。处于公开状态时，发布时间不再改到未来；撤回后重新发布会产生新的公开时间。
_Avoid_: 把编辑已发布公告当成再次发布。

**已失效（Expired announcement）**:
到达失效时间的已发布公告。不再占用首页近期公告，但仍保留在全部公告与详情页，作为历史记录。
_Avoid_: 已撤回；失效不是私有化。

**已撤回（Withdrawn announcement）**:
Admin 主动从公开页面下线的已发布或已失效公告。首页、全部公告与详情页均不再公开；可在后台立即或定时重新发布。
_Avoid_: 删除；撤回保留公告记录，重新发布不会重发通知。

**公告通知（Announcement notification）**:
公告首次公开时可向当时所有未封禁 User 投递的「通知」。它记录发布事实，只发送一次；公告后来编辑、失效或撤回都不重复发送，也不删除既有通知。来源不可访问时，点击通知进入「消息不存在」。遵循[通知上下文](../notifications/CONTEXT.md)的独立生命周期。
_Avoid_: 把通知当作公告副本；撤回公告时删除通知。

## State transitions

- 草稿 → 待发布 / 已发布
- 待发布 → 草稿 / 已发布
- 已发布 → 已失效 / 已撤回
- 已失效 → 已撤回
- 已撤回 → 待发布 / 已发布
