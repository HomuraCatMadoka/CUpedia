# 产品更新（Product Updates）

面向全站读者记录 CUpedia 已经上线的产品变化。产品更新公开可读；编写与发布仅限 Admin。

本文件只是术语表，不记录实现。

## Language

**产品更新（Product update）**:
一条面向用户、永久可引用的产品变化记录，说明 CUpedia 新增、改善、修复或调整了什么，以及这项变化对学生有什么帮助。首版由 Admin 创建后立即公开，使用稳定 UUID 详情链接。
_Avoid_: 公告；开发日志；把 commit、PR 或内部重构自动发布给用户。

**更新类型（Update type）**:
产品变化的受控分类，只能是「新功能」「体验改善」「问题修复」「功能调整」之一。类型表达变化的性质，不表达重要程度。
_Avoid_: Admin 自由输入类型；把产品领域当作更新类型。

**产品领域（Product area）**:
产品更新影响的 CUpedia 功能范围。首批受控值为「百科」「课程」「食堂」「地图」「账户」；一条产品更新可以影响多个产品领域。
_Avoid_: 自由标签；用产品领域替代限界上下文的领域语言。

**公告（Announcement）**:
需要读者及时知道或采取行动的站点消息，可以拥有独立的可见性、失效与通知生命周期。产品更新不自动发送站内通知；重要产品变化需要主动触达时，应另行创建公告。
_Avoid_: 因产品更新发布而自动广播通知；让公告失效影响产品更新的永久记录。

## First release scope

- Admin 立即发布纯文本产品更新。
- 匿名读者和 User 从全局导航进入公开列表，并浏览永久详情页。
- 不包含草稿、排期、撤回、富文本、媒体、RSS、订阅、已读状态或自动生成发布说明。
