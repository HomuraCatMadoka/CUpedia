# CUHK bus route geodata

The JSON files in this directory provide the route polylines and stop
occurrence coordinates used by the passenger map for routes 1A, 1B, 3, 4, 5,
6A, 6B, 7, 8, N, and H. They are derived from audited OpenStreetMap route
relations and carry their relation id, version, timestamp, source URL,
attribution, and ODbL licence in each file.

The geodata is deliberately occurrence-aware. A loop route may pass the same
physical stop more than once, so each map point is aligned to the reviewed
official stop sequence and receives an id such as `stop-id#1` or `stop-id#2`.
The passenger map can group co-located occurrences visually without merging
their timetable identities.

## Rebuild a route

Download the relation's full OSM representation, then run:

```bash
pnpm exec tsx scripts/cuhk-bus-osm-geodata.ts \
  /path/to/relation-full.json \
  docs/campus-transport/data/cold-start/route-1a.staging.json \
  docs/campus-transport/data/geodata/route-1a.osm.json
```

The generator fails closed when the number of OSM platform occurrences does
not equal the reviewed official stop sequence. It may remove an exact,
consecutive duplicate platform member, but records the ignored node id in the
output provenance. This handles the audited 6A and H relation defects without
changing the official stop sequence.

`N*` is the 00-minute variant with PGH1 in both directions. `H*` is the

covers the canonical longest pattern; shorter patterns reuse the shared stop
occurrences and road shape.

Route 8's relation covers its 16-stop teaching-day pattern. The
non-teaching-day pattern shares the first 15 stops, then uses separately
audited Station Piazza and Chung Chi Teaching Building coordinates; the
current OSM relation does not provide that final road segment.

regenerated by this OSM pipeline yet.
