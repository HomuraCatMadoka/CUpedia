# 通知（Notifications）

给 User 集中查看来自各业务上下文、与本人相关的站内消息。通知中心负责投递与阅读状态，不拥有产生消息的业务事实。

本文件只是术语表，不记录实现。

## Language

**通知中心（Notification center）**:
全站通用的 User 收件箱，汇集各业务上下文发给同一 User 的「通知」。
_Avoid_: 课程回复提醒页；把通知中心归属于某一个业务上下文。

**通知（Notification）**:
某个业务事实面向特定 User 的站内消息；它引用来源，但不取代来源上下文中的事实，其生命周期与来源分离。来源删除后通知仍可存在，User 尝试进入来源时看到「消息不存在」；通知本身不自动过期，也不由 User 删除。
_Avoid_: 业务事件、系统日志；把通知与来源级联删除；把通知当作来源内容的副本；把已读当作删除。

**未读（Unread）**:
尚未被 User 明确处理的通知状态；只浏览通知中心不会改变它，点击通知进入来源或执行「全部标为已读」才会转为已读。通知中心入口在未读数为零时不显示角标，1–9 时显示准确数字，10 及以上显示 `9+`。
_Avoid_: 打开通知中心即全部已读；把通知总数当作未读数。

**课程评论回复通知（Course review reply notification）**:
其他 User 回复某条课程评论时，面向原评论作者产生的「通知」；原作者回复自己的评论不产生通知，其他既有回复者也不是收件人。匿名原评论仍按内部 User 归属投递，不改变其公开匿名性；通知只标识回复者、课程与发生时间，不复制回复正文。User 点击通知后直接定位到原评论并展开其回复区，来源不存在时则看到「消息不存在」。
_Avoid_: 通知所有参与者；用通知暴露匿名原评论作者；保存或展示回复正文副本。
