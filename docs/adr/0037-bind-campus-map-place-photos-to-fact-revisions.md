# ADR 0037：Campus Map 地点照片绑定事实修订而不是评价

地点照片回答“这个地点长什么样、入口和设备在哪里”，并不表达某位用户的主观体验。照片因此
属于具体 Place 的 Fact revision：所有已登录且未封禁的用户都能先上传照片；照片随新增或编辑
发布时继续遵守现有地图贡献资格。当前版本合计最多三张；Pin type 只用一组共享的受控照片视角
给出场景化拍摄提示。
这替代 ADR 0036 后果中“#818 的照片沿用 feedback ID”的预告，但不改变其评分和评价模型。

## 决议

照片先作为上传者拥有的短生命周期私有资源完成服务端验证、旋转、去 metadata、压缩和频率
限制，再与事实发布在同一数据库事务中按顺序绑定到新 revision。更新地点时可以保留前一版本
由其他用户上传的照片，但新加入的资源必须属于当前发布者，而且已经绑定过的资源只能沿同一
Place 的后续版本复用；最多三张的约束同时在命令校验和数据库中执行。公开读取只提供 active
Place 当前 revision 已绑定的 ready 资源，旧 revision 仍保留绑定作历史证据但不作为公共图库
继续提供。

## 后果

- 评价继续只有星级和可选文字，隐藏评价不会让地点照片消失。
- 图片跟随不可变地点版本，因此新增、移除或排序图片也是一次可审计的地点变更。
- 首版反向修订只恢复结构化地点事实，不恢复目标 revision 的照片；照片沿用当前 base，后续可作为普通地点照片变更调整。
- 首版不加入评论图片、图钉类型图库、独立相册、裁切器、滤镜、影片、点赞或逐图审核。
