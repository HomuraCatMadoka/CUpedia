# ADR 0043：校园地图只对洗手间展示清洁度评价

本决议收窄 ADR 0036 的产品适用范围，不改变既有反馈表、作者身份、版本、可见性、删除、
治理与合并规则。

## 决议

校园地图只为洗手间 Place 展示评分入口、公开评价和地图评分摘要。星级明确表示清洁度，评价
文字用于补充当次到访体验。其他设施更需要位置、服务能力和故障等事实信息，因此不展示通用
星级或评价入口。

既有非洗手间反馈不删除，继续保留原有稳定 ID 与治理关联，但不再显示在地图、地点详情和
评分摘要中。用户报告位置错误、设施故障或资料缺失时，继续使用 Place 纠错或 Map Note 流程。

## 后果

- 洗手间详情默认先展示摘要和公开评价，用户主动选择“评价清洁度”后才展开表单。
- 地图列表只读取和显示洗手间评分摘要。
- 普通设施详情不再被与用途无关的星级表单占据。
- 如以后为公共空间等类型引入评价，须先定义有意义的评价维度，不能直接复用通用星级。
